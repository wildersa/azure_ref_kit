# Solution families

This directory contains reusable solution families consolidated from active Solution Opportunities.

The catalog preserves this separation:

```text
business opportunity
→ reusable solution family
→ applied case and case-specific adaptations
→ possible derived-architecture candidate
```

A family owns the reusable logical architecture, invariant capabilities, intelligent mechanism, deterministic controls, human authority, integration contract, evaluation, security, and building blocks. The original opportunity remains the source of truth for the business actor, bounded process, Brazilian context, evidence, regulation, case data, hypothesis, and prototype.

Do not create a family from a shared AI label alone. A family requires a materially compatible trigger, execution model, information transformation, intelligent mechanism, deterministic-control boundary, human authority, integration shape, feedback, abstention, and failure behavior.
