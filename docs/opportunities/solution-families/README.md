# Solution Families

This folder contains reusable logical solution patterns consolidated from concrete opportunities.

A solution family is not a market segment, Azure service list, generic AI capability, or implementation backlog.

Each family must:

- represent a repeated architectural spine;
- retain one concrete operational outcome;
- define invariants and variation points;
- identify one primary intelligent mechanism;
- preserve deterministic and human authority boundaries;
- list applied opportunities and case-specific adapters;
- defer architecture variants to a separate derivation review.

Concrete business context, regulation, evidence, actors, and prototype assumptions remain in the opportunity documents under `segments/`.

Use `../solution-family-template.md` and follow `../solution-consolidation-method.md`.
